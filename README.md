# Левоновий Владислав
# Лабораторна робота N 4 Рівень-2 Варіант-2
# Реалізовано чергу з пріоритетами на базі бінарного дерева. Кожен вузол має значення і пріоритет. Дерево побудоване так, що батьківський вузол має вищий пріоритет за правого нащадка і не більший за лівого. Підтримуються операції вставки, видалення елемента з найвищим пріоритетом і перегляду черги.
