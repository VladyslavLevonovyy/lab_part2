# Левоновий Владислав
# Лабораторна робота № 6
# Варіант-2 Рівень-2
# У цій лабораторній ми реалізували програму для знаходження максимальної суми досвіду в ієрархічній структурі компанії у вигляді піраміди.

Ми зчитали дані з файлу та застосували динамічне програмування — проходили піраміду знизу вгору, на кожному рівні обираючи максимальний досвід із можливих переходів.

У результаті отримали максимальний можливий досвід, який можна набрати, піднімаючись з найнижчого рівня до вершини, і записали його у вихідний файл.
