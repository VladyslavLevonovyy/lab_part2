## Лабораторна робота N9  Варіант-2


## Є N опор, розташованих на однаковій відстані w одна від одної. Для кожної опори задано її максимальну можливу висоту. Потрібно вибрати конкретну висоту для кожної опори (від 1 до максимальної), щоб сумарна довжина дроту, яким з’єднуються вершини сусідніх опор, була максимальною. Вивести цю довжину з точністю до 2 знаків після коми.
